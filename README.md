# Dorm Guardian / Smart Room Guardian

A student portfolio project for a secure smart room monitoring system.

## Current status

Mock version in progress.

The first version simulates sensor data before the real STM32, Raspberry Pi, sensors, camera, servo, and fan arrive.

## Planned features

- Mock sensor data generation
- FastAPI backend
- SQLite database
- React dashboard
- Fan automation simulation
- Alert system
- Secure device ingestion
- Authentication
- Local-only abuse-defense testing
- Later: STM32 + Raspberry Pi + OpenCV + servo + fan integration

## Tech stack

- Python
- FastAPI
- SQLite
- React
- TypeScript
- OpenCV later
- STM32 later
- Raspberry Pi later
